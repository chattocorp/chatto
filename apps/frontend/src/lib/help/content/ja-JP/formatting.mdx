Chatto のメッセージは Markdown で書式を設定できます。たとえば、`**こんにちは**` は **こんにちは** と表示されます。書式の記号を自分で入力するか、テキストを選択して書式ツールバーを使ってください。

## エディターと送信ショートカットを選ぶ

<a href={resolve('/chat/preferences/composer')}>アプリ設定 → メッセージ作成</a>
を開き、元のテキストを編集するには **Markdown** を選びます。書式が付いたテキストを直接編集したい場合は、**ビジュアル**を選びます。どちらのエディターでも書式ツールバーを使えます。

**メッセージの送信キー**の設定で Enter キーの動作が決まります。

- **Return：**Enter で送信します。Ctrl+Enter、Mac では Command+Enter で改行します。
- **Cmd/Ctrl+Return：**Ctrl+Enter、Mac では Command+Enter で送信します。Enter で改行します。

段落の間には空行を入れてください。

## 太字、斜体、下線、取り消し線

テキストの両側に書式の記号を置きます。

- `**太字**` は太字
- `*斜体*` は斜体
- `__下線__` は下線
- `~~取り消し線~~` は取り消し線

<MarkdownSample source={"**金曜日までに** 確認してください。\n日程は *仮のもの* です。\n__承認が必要__ です。公開前に確認してください。\n以前の期限は ~~木曜日~~ でした。"} />

Chatto では `__テキスト__` は下線を意味します。ほかの Markdown ツールで二重のアンダースコアを太字に使っている場合は、ここでは二重のアスタリスクに変えてください。

テキストを選択して Ctrl+B、Ctrl+I、Ctrl+U を押すと、それぞれ太字、斜体、下線を設定できます。Mac では Ctrl の代わりに Command を使います。ツールバーのボタンも同じ操作を行います。

記号とテキストの間に空白を入れないでください。`**重要**` は機能しますが、`** 重要 **` は太字になりません。

## 見出しとリスト

見出しは `#` の後に空白を入れて始めます。箇条書きの各項目は `- `、番号付きの項目は `1. ` のように数字とピリオドで始めます。

<MarkdownSample source={"## リリースのチェックリスト\n\n開始前：\n- バージョンを確認する。\n- サポートチームに知らせる。\n\nその後：\n1. 更新をデプロイする。\n2. ステータスページを確認する。\n3. 結果をここに投稿する。"} />

ツールバーの**見出し**ボタンはレベル 2 の見出し（`##`）を挿入します。`#` から `######` までの見出しレベルを手動で入力することもできます。

**インデントを増やす**を使うと、リスト項目を直前の項目の下に入れ子にできます。**インデントを減らす**で元に戻します。リストの後で段落を始めるには、空行を入れてください。

## 引用

引用する各行を `>` と空白で始めます。引用の後に空行を入れてから返信を書きます。

<MarkdownSample source={"> リリースを金曜日に変更できますか？\n\nはい。最終確認は木曜日の午後です。"} />

引用を入力しても、元のメッセージへのリンクにはなりません。そのメッセージにスレッドで返信するには、メッセージの返信操作を使ってください。

## コード

短いコマンド、ファイル名、識別子の両側にバッククォートを 1 つずつ置きます。インラインコード内の書式記号は入力どおりに表示されます。

<MarkdownSample source={"開始前に `git status` を実行してください。\n設定の名前は `send_mode` です。\n`**こんにちは**` と入力すると、こんにちはが太字になります。"} />

複数行の場合は、コードの前後にバッククォート 3 つだけの行を置きます。開始側のバッククォートの直後に `js`、`json`、`bash` などの言語名を追加すると、構文が強調表示されます。

<MarkdownSample source={"```js\nconst release = '0.5';\nconsole.log(release);\n```"} />

ツールバーの**コードブロック**ボタンは、開始と終了のバッククォートを挿入します。終了行がないと、メッセージの残りがコードブロックになります。インラインコード内にバッククォートを表示するには、テキストの両側にバッククォートを 2 つずつ置きます。

## リンク

貼り付けた Web アドレスはリンクになります。アドレスの代わりにラベルを表示するには、ラベルを角括弧、アドレスを丸括弧で囲みます。

```text
[リリースノート](https://example.com/releases)を読んでください。
```

`]` と `(` の間に空白を入れないでください。Chatto のルームへのリンクや人へのメンションは、エディターの候補から選んでください。

## 脚注

注釈を付けたいテキストの後に `[^window]` のような参照を置きます。別の行に `[^window]:` と注釈を書きます。両方のラベルは同じにしてください。

<MarkdownSample source={"メンテナンス時間は 30 分です。[^window]\n\n[^window]: ほとんどのサーバーの停止時間は 5 分未満です。"} />

対象のテキストの後にカーソルを置き、ツールバーの**脚注を挿入**を選ぶこともできます。インラインコードやコードブロックの中には脚注を挿入できません。

## 表

列を `|` で区切り、列見出しの下にハイフンの行を置きます。`---:` は右寄せ、`:---:` は中央揃えです。

<MarkdownSample source={"| 環境 | バージョン |\n| --- | ---: |\n| テスト | 0.5 |\n| 本番 | 0.4 |"} />

表は Markdown エディターで編集してください。ビジュアルエディターには表を編集する操作がありません。

## 完成したメッセージで試す

下のメッセージを編集して、書式を試してください。入力するとプレビューが更新されます。Markdown とビジュアルのエディターを切り替えられます。ここに入力した内容がルームに送信されることはありません。

<div class="my-10">
  <FormattingExample showReference={false} initialValue={"## 金曜日のリリース\n\n**14:00 までに** 確認を終えてください。\n\n1. `git status` を実行する。\n2. リリースノートを確認する。\n3. 準備ができたら、このスレッドに返信する。\n\n> 確認に失敗したらどうしますか？\n\n続行する前に、エラーをここに投稿してください。"} />
</div>

## 書式が正しく表示されないとき

- **記号がそのまま見える。** 両端の記号が一致しているか、開始記号の直後や終了記号の直前に空白がないかを確認してください。コード内では、記号が見えるのが正常です。
- **メッセージの残りがコードになる。** 終了のバッククォート 3 つを独立した行に置いてください。
- **見出しやリストが通常のテキストのまま。** `##`、`-`、`1.` の後に空白を入れ、新しい行から始めてください。
- **記号そのものを表示したい。** `\*斜体にしない\*` のように書式記号の前にバックスラッシュを置くか、文字どおりの例にはインラインコードを使ってください。
- **HTML がテキストとして表示される。** Chatto はメッセージの書式に生の HTML を受け付けません。`<b>` や `<span>` などのタグではなく Markdown を使ってください。
