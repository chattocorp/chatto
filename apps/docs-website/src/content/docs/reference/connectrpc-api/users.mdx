## UserService

Reads users and manages public user profiles and avatars.

<a id="chatto-api-v1-UserService-ListUsers"></a>

### ListUsers

Lists users visible to the authenticated user. Admin-sensitive account
fields stay out of this public row shape.

```http
POST /api/connect/chatto.api.v1.UserService/ListUsers
```

Request for users visible to the authenticated user.

<a id="chatto-api-v1-UserService-UpdateUserProfile"></a>

### UpdateUserProfile

Updates the target user's login, display name, and/or bio. Users can
update themselves. Updating another human requires user.manage-accounts.
Updating a bot requires ownership, user.manage-accounts, or bot.manage.
A bot cannot target another account. A self login change starts the
username-change cooldown and fails while the cooldown is active, unless
the caller has user.manage-accounts. Changes to another account do not
apply or reset the target's cooldown. Unknown or deleted targets return
NOT_FOUND.

```http
POST /api/connect/chatto.api.v1.UserService/UpdateUserProfile
```

<a id="chatto-api-v1-UpdateUserProfileRequest"></a>

#### Input: UpdateUserProfileRequest

Request to update one user's public profile. update_mask selects fields
to apply or reset. Fields outside the mask stay unchanged.

| Field | Type | Description |
| --- | --- | --- |
| `user_id` | `string` | Required target user ID. Self-updates are allowed. Updating another user requires the applicable account-management or bot-management authority. |
| `display_name` | `optional string` | New non-empty display name. The server also rejects control and confusing invisible characters. |
| `login` | `optional string` | New login identifier, when changing it. The server accepts ASCII letters, digits, period, underscore, and hyphen, starting with a letter or digit. |
| `bio` | `optional string` | New Markdown biography, when changing it. Empty clears the bio. |
| `update_mask` | `google.protobuf.FieldMask` | Editable fields to apply or reset: display_name, login, bio. Omit to infer populated fields; * selects all editable fields. An explicit empty mask is invalid. Unselected values are ignored. Selected absent values reset the field to its default, subject to field validation. |


<a id="chatto-api-v1-UpdateUserProfileResponse"></a>

#### Result: UpdateUserProfileResponse

Result of a user profile update.

| Field | Type | Description |
| --- | --- | --- |
| `user` | [`User`](/reference/connectrpc-api/types/#chatto-api-v1-User) | Updated user profile. |


<a id="chatto-api-v1-UserService-UploadAvatar"></a>

### UploadAvatar

Uploads and sets an avatar for the target user. Users can update
themselves. Updating another human requires user.manage-accounts.
Updating a bot requires ownership, user.manage-accounts, or bot.manage.
A bot cannot target another account. Unknown or deleted targets return
NOT_FOUND. Invalid IDs or missing images return INVALID_ARGUMENT.

```http
POST /api/connect/chatto.api.v1.UserService/UploadAvatar
```
