אפשר להתקין את Chatto מדפדפן הטלפון. מתקבל סמל במסך הבית, והאפליקציה נפתחת בחלון משלה ללא שורת הכתובת של הדפדפן.

השתמש בכתובת Chatto שאליה אתה מתחבר בדרך כלל, למשל `https://chat.example.com`. אם קיבלת קישור בתוך אפליקציה אחרת, העתק אותו תחילה לדפדפן. נדרשת כתובת HTTPS כדי להתקין את האפליקציה ולהשתמש בהתראות דחיפה.

## iPhone: התקנה דרך Safari

1. פתח את כתובת Chatto ב־**Safari**.
2. פתח **שיתוף** — הריבוע עם החץ כלפי מעלה. בהתאם לפריסת Safari, ייתכן שצריך לפתוח תחילה את תפריט העמוד.
3. בחר **הוסף למסך הבית**. אם האפשרות חסרה, השתמש ב־**עריכת פעולות** כדי להוסיף אותה.
4. השאר את **פתח כיישום אינטרנט** מופעל אם Safari מציג אפשרות זו, ואז בחר **הוסף**.
5. פתח את Chatto מהסמל החדש במסך הבית. התחבר אם תתבקש.

ראה את [הוראות ההתקנה של Apple](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios) אם האפשרויות בטלפון שונות.

## Android: התקנה דרך Chrome

1. פתח את כתובת Chatto ב־**Chrome**.
2. פתח את **תפריט שלוש הנקודות** לצד שורת הכתובת.
3. בחר **התקנה ויצירת קיצור דרך**, ואז **התקנה**. בחלק מהגרסאות מופיע **התקנת אפליקציה** או **הוספה למסך הבית** במקום זאת.
4. אשר את ההתקנה ופתח את Chatto מסמל האפליקציה. התחבר אם תתבקש.

ראה את [הוראות ההתקנה של Google](https://support.google.com/chrome/answer/9658361?hl=en&co=GENIE.Platform%3DAndroid) לשלבים העדכניים ב־Chrome.

### אם אתה משתמש ב־Firefox

פתח את כתובת Chatto ב־Firefox, פתח את **תפריט שלוש הנקודות** ובחר **התקנה**. בחר **הוספה אוטומטית**, או גרור את הסמל למסך הבית. לאחר מכן פתח את Chatto מהסמל הזה.

ראה את [הוראות Mozilla עבור Firefox ב־Android](https://support.mozilla.org/en-US/kb/use-web-apps-firefox-android).

## הפעל התראות

פתח את האפליקציה המותקנת לפני הפעלת התראות. ב־iPhone, המשמעות היא פתיחת Chatto מהסמל במסך הבית, ולא מכרטיסייה ב־Safari.

1. פתח את הגדרות **התראות** של השרת.
2. הפעל **התראות דחיפה במכשיר הזה** ואפשר התראות כשהטלפון מבקש.
3. בחר **שלח הודעת בדיקה** כדי לבדוק את המסירה.

התקנת האפליקציה אינה מעניקה הרשאה להתראות. אם התראת הבדיקה לא מגיעה, בדוק את הגדרות ההתראות בטלפון ואת מצב הריכוז או ״נא לא להפריע״. אם Chatto מדווח שדחיפה אינה זמינה בשרת, בקש מהמנהל להפעיל Web Push.

הטלפון יכול להציג שמות ותצוגות מקדימות של הודעות במסך הנעילה. שנה זאת בהגדרות ההתראות בטלפון אם אינך רוצה שיופיעו שם תצוגות מקדימות.

## שיחות ב־iPhone

בשיחות באפליקציית האינטרנט המותקנת, השמע עלול להיפסק בעת מעבר לאפליקציה אחרת או נעילת המסך. השאר את Chatto פתוח ואת המסך לא נעול בזמן שיחה. כרטיסייה רגילה של Safari עשויה לעבוד בצורה אמינה יותר לשיחות מאשר האפליקציה המותקנת.

אם השמע נפסק, חזור ל־Chatto ובחר **הפעלת שמע השיחה** אם האפשרות מופיעה. אם השמע לא חזר, צא מהשיחה והצטרף שוב, או פתח את Chatto מחדש ב־Safari. עדכן את iOS; ההתנהגות עשויה להשתנות בין גרסאות.

## השתמש ביותר משרת אחד

אפשר להתחבר לכמה שרתים באפליקציית Chatto מותקנת אחת ולעבור ביניהם. אם אתה מעדיף סמל נפרד לכל קהילה, התקן את Chatto מהכתובת של כל שרת.

האפליקציה המותקנת עדיין זקוקה לחיבור כדי לטעון הודעות ולשלוח תשובות. היא אינה מורידה את היסטוריית הצ'אט לשימוש ללא חיבור.
