---
title: Use Threads
description: Open a thread and choose how Chatto shows the thread pane.
---

Use a thread to keep a focused conversation with its root message.

Select **Post as thread** when you write a new room message to start its
thread. After you post, the room stays open. Select the new message's thread
link to open the thread pane.

## Open and close a thread

Select **Reply in thread** or **Open thread** on a room message. Chatto opens the thread pane and keeps the thread in the page address. You can copy that address to share the open thread.

Select the back button or close button in the thread pane to return to the room. You can also press Escape. When the thread overlays the room, you can select the dimmed room timeline to close the thread.

## Find your threads

Open **Threads** and select a tab:

- **Followed** is the default view. It shows all threads you follow, including
  threads you started.
- **Mine** shows threads that you started and still follow.

Unfollowing removes a thread from either tab. Use **Unread** to show only
threads with unread replies. Switching tabs keeps your search and unread filter.

Use **Activity** to put threads with the latest activity first. This is the
default order. Use **Age** to put the most recently created threads first.
Date sections use the selected sort date. The selection stays in place when
you search, switch tabs, or return from a thread.

## Search your followed threads

Select a tab in **Threads** and enter words, a quoted phrase, or a filter in the search
field. Search checks root messages and all replies in threads you follow,
including DM threads. Each matching thread appears once, in the selected
**Activity** or **Age** order. Select **Unread** to show only matching threads with
unread replies.

Use `from:username` to find messages by an author. Plain words search message
text. Clear the field to restore the full list.
The field is available when your server supports and enables message search.

## Choose the thread pane layout

Select the App Preferences gear in the Application Header. Open **Appearance**, find **Thread pane**, and select one of these options:

- **Overlay** shows the thread over the room timeline. The room timeline is dimmed and inactive while the thread is open. This is the default.
- **Side by side** shows the room timeline and thread as two interactive panes when there is enough space. Drag the resize handle to change the thread width. Chatto uses the overlay when the room area becomes too narrow.

The setting and the side-by-side width apply to every Chatto server in the current browser. They do not sync to other browsers or devices.
