## AdminJobService

Administrative background-job inspection and recovery.

<a id="chatto-admin-v1-AdminJobService-ListJobs"></a>

### ListJobs

Lists jobs. Requires server.manage, including privileged mode.
This call does not subscribe or poll; callers refresh explicitly.

```http
POST /api/connect/chatto.admin.v1.AdminJobService/ListJobs
```

<a id="chatto-admin-v1-ListJobsRequest"></a>

#### Input: ListJobsRequest

Request for a bounded page. Jobs are ordered by last update, newest first.

| Field | Type | Description |
| --- | --- | --- |
| `page_size` | `uint32` | Page size: zero selects 50; the maximum is 200. |
| `cursor` | `string` | Opaque cursor returned by the previous page, bound to this viewer and status filter. Empty starts at the newest job. |
| `status` | [`JobStatus`](/reference/connectrpc-api/types/#chatto-admin-v1-JobStatus) | Returns only jobs in this state. Unspecified returns every job. |


<a id="chatto-admin-v1-ListJobsResponse"></a>

#### Result: ListJobsResponse

A live page, not an atomic snapshot. Refresh to see state changes and new work.

| Field | Type | Description |
| --- | --- | --- |
| `jobs` | repeated [`Job`](/reference/connectrpc-api/types/#chatto-admin-v1-Job) | Current summaries. |
| `next_cursor` | `string` | Cursor for the next page. Empty when there are no more jobs in this traversal. |

<a id="chatto-admin-v1-AdminJobService-RetryJob"></a>

### RetryJob

Retries a failed job. Requires server.manage, including privileged mode.
Returns FAILED_PRECONDITION for active, successful, or expired jobs.
A lost response does not cancel an accepted retry. Read the job before retrying.

```http
POST /api/connect/chatto.admin.v1.AdminJobService/RetryJob
```

<a id="chatto-admin-v1-RetryJobRequest"></a>

#### Input: RetryJobRequest

Request to start a new attempt budget for a failed, unexpired job.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Required stable job ID. Concurrent requests cannot queue two generations. |
| `version` | `string` | Version from the failed Job. Rejects stale actions even if a newer budget has already failed. It is not a request ID or a storage coordinate. |


<a id="chatto-admin-v1-RetryJobResponse"></a>

#### Result: RetryJobResponse

Accepted retry. The worker can have started before this response arrives.

| Field | Type | Description |
| --- | --- | --- |
| `job` | [`Job`](/reference/connectrpc-api/types/#chatto-admin-v1-Job) | Job after durable retry acceptance. |


<a id="chatto-admin-v1-AdminJobService-DeleteJob"></a>

### DeleteJob

Deletes a failed job. Requires server.manage, including privileged mode.
The work of the job is abandoned and cannot be retried later. Returns
FAILED_PRECONDITION when the job is not failed or changed after the caller
read it, and NOT_FOUND when it is already deleted.

```http
POST /api/connect/chatto.admin.v1.AdminJobService/DeleteJob
```

<a id="chatto-admin-v1-DeleteJobRequest"></a>

#### Input: DeleteJobRequest

Request to delete a failed job, for example one that can never succeed.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Required stable job ID. |
| `version` | `string` | Version from the failed Job. Rejects the request when the job changed after the caller read it, for example through a retry. |


<a id="chatto-admin-v1-DeleteJobResponse"></a>

#### Result: DeleteJobResponse

The job is deleted.
