## AdminOAuthClientService

Manages OAuth clients authorized through this server. Requires server.manage.

<a id="chatto-admin-v1-AdminOAuthClientService-ListOAuthClients"></a>

### ListOAuthClients

Lists clients that completed at least one authorization. Requires server.manage.

```http
POST /api/connect/chatto.admin.v1.AdminOAuthClientService/ListOAuthClients
```

<a id="chatto-admin-v1-ListOAuthClientsRequest"></a>

#### Input: ListOAuthClientsRequest

Lists OAuth clients with recorded authorizations using offset pagination.

| Field | Type | Description |
| --- | --- | --- |
| `page` | [`chatto.api.v1.PageRequest`](/reference/connectrpc-api/types/#chatto-api-v1-PageRequest) | Requested offset and page size. |


### UpdateOAuthClientPolicy

Replaces a client's policy and revokes tokens when blocked. Requires server.manage.

```http
POST /api/connect/chatto.admin.v1.AdminOAuthClientService/UpdateOAuthClientPolicy
```

<a id="chatto-admin-v1-UpdateOAuthClientPolicyRequest"></a>

#### Input: UpdateOAuthClientPolicyRequest

Replaces the administrative policy for one OAuth client.

| Field | Type | Description |
| --- | --- | --- |
| `client_id` | `string` | Exact CIMD URL or built-in application URI. |
| `policy` | [`OAuthClientPolicy`](/reference/connectrpc-api/types/#chatto-admin-v1-OAuthClientPolicy) | New complete policy value. Default removes any trusted or blocked label. |

| Field | Type | Description |
