## NotificationPolicyService

Reads and updates the authenticated viewer's server, room-group, and room
notification delivery policies.

<a id="chatto-api-v1-NotificationPolicyService-GetNotificationPolicy"></a>

### GetNotificationPolicy

Gets explicit and effective modes for one policy scope. Returns NOT_FOUND
for a missing room group or room, and PERMISSION_DENIED when the viewer is
not a current member of a requested room.

```http
POST /api/connect/chatto.api.v1.NotificationPolicyService/GetNotificationPolicy
```

### BatchGetNotificationPolicies

Gets an explicit bounded set of policies. Missing and inaccessible scopes
are omitted, and duplicate scopes are de-duplicated in first-seen order.

```http
POST /api/connect/chatto.api.v1.NotificationPolicyService/BatchGetNotificationPolicies
```

<a id="chatto-api-v1-NotificationPolicyService-UpdateNotificationPolicy"></a>

### UpdateNotificationPolicy

Atomically sets or clears selected overrides at one explicit scope.

```http
POST /api/connect/chatto.api.v1.NotificationPolicyService/UpdateNotificationPolicy
```

<a id="chatto-api-v1-NotificationPolicyServiceUpdateNotificationPolicyRequest"></a>

#### Input: NotificationPolicyServiceUpdateNotificationPolicyRequest

Sparsely update notification policy overrides at one explicit scope.

| Field | Type | Description |
| --- | --- | --- |
| `scope` | [`NotificationPolicyScope`](/reference/connectrpc-api/types/#chatto-api-v1-NotificationPolicyScope) | Required policy scope. |
| `overrides` | [`NotificationDeliveryModes`](/reference/connectrpc-api/types/#chatto-api-v1-NotificationDeliveryModes) | Sparse override values. Fields selected by update_mask but absent here are cleared to Inherit. |
| `update_mask` | `google.protobuf.FieldMask` | Fields to set or clear, relative to overrides. The mask must contain at least one supported delivery-mode field. |
