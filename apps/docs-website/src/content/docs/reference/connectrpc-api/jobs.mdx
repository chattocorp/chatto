## JobsService

Administrative background-job inspection and recovery.

<a id="chatto-admin-v1-JobsService-ListJobs"></a>

### ListJobs

Lists jobs. Requires server.manage, including privileged mode.
This call does not subscribe or poll; callers refresh explicitly.

```http
POST /api/connect/chatto.admin.v1.JobsService/ListJobs
```

<a id="chatto-admin-v1-ListJobsRequest"></a>

#### Input: ListJobsRequest

Request for a bounded page. Jobs are ordered by last update, newest first.

| Field | Type | Description |
| --- | --- | --- |
| `page_size` | `int32` | Page size: zero selects 50; the maximum is 200. |
| `page_token` | `string` | Opaque token returned by the previous page, bound to this viewer and status filter. |
| `status` | [`JobStatus`](/reference/connectrpc-api/types/#chatto-admin-v1-JobStatus) | Returns only jobs in this state. Unspecified returns every job. |


<a id="chatto-admin-v1-ListJobsResponse"></a>

#### Result: ListJobsResponse

A live page, not an atomic snapshot. Refresh to see state changes and new work.

| Field | Type | Description |
| --- | --- | --- |
| `jobs` | repeated [`Job`](/reference/connectrpc-api/types/#chatto-admin-v1-Job) | Current summaries. |
| `next_page_token` | `string` | Empty when there are no more jobs in this traversal. |

<a id="chatto-admin-v1-JobsService-RetryJob"></a>

### RetryJob

Retries a failed job. Requires server.manage, including privileged mode.
Returns FAILED_PRECONDITION for active, successful, or expired jobs.
A lost response does not cancel an accepted retry. Read the job before retrying.

```http
POST /api/connect/chatto.admin.v1.JobsService/RetryJob
```

<a id="chatto-admin-v1-RetryJobRequest"></a>

#### Input: RetryJobRequest

Request to start a new attempt budget for a failed, unexpired job.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Required stable job ID. Concurrent requests cannot queue two generations. |
| `retry_version` | `string` | Version from the failed Job. Rejects stale actions even if a newer budget has already failed. It is not a request ID or a storage coordinate. |


<a id="chatto-admin-v1-RetryJobResponse"></a>

#### Result: RetryJobResponse

Accepted retry. The worker can have started before this response arrives.

| Field | Type | Description |
| --- | --- | --- |
| `job` | [`Job`](/reference/connectrpc-api/types/#chatto-admin-v1-Job) | Job after durable retry acceptance. |
