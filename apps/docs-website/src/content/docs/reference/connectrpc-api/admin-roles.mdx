## AdminRoleService

Provides authenticated role reads and administrative role definition changes.

<a id="chatto-admin-v1-AdminRoleService-ListRoles"></a>

### ListRoles

Lists the role catalog including permission arrays as a finite snapshot.
Requires an authenticated user. This intentionally includes permission
arrays for clients that need to show a user's assigned roles and their
effects; use chatto.api.v1.RoleService for lightweight catalog rendering.

```http
POST /api/connect/chatto.admin.v1.AdminRoleService/ListRoles
```

<a id="chatto-admin-v1-ListRolesRequest"></a>

#### Input: ListRolesRequest

Request the role catalog.


<a id="chatto-admin-v1-ListRolesResponse"></a>

#### Result: ListRolesResponse

Finite role catalog snapshot plus viewer role-management capabilities.

| Field | Type | Description |
| --- | --- | --- |
| `roles` | repeated [`AdminRole`](/reference/connectrpc-api/types/#chatto-admin-v1-AdminRole) | Roles in role order, highest first. |
| `viewer_can_manage_roles` | `bool` | Whether the caller may create/update/delete role definitions. |
| `viewer_can_assign_roles` | `bool` | Whether the caller may assign/revoke roles and view role rosters. |

### ListMembers

Lists explicit role members. Requires role.assign, without requiring
admin.view-users. Returns NOT_FOUND when the role does not exist.

```http
POST /api/connect/chatto.admin.v1.AdminRoleService/ListMembers
```

<a id="chatto-admin-v1-AdminRoleServiceListMembersRequest"></a>

#### Result: AdminRoleServiceListMembersResponse

Explicit members sorted by user ID. Each page is a live read; assignment

### DeleteRole

Deletes a custom role. Requires role.manage. A caller who is not an owner
must have every permission that the role allows or denies, at the same
scope; otherwise the call returns PERMISSION_DENIED.

<a id="chatto-admin-v1-AdminRoleService-MoveRole"></a>

### MoveRole

Moves one role in the role order. Requires role.manage. The caller can
move every role except owner and everyone, also above their own highest
role.

```http
POST /api/connect/chatto.admin.v1.AdminRoleService/MoveRole
```

<a id="chatto-admin-v1-MoveRoleRequest"></a>

#### Input: MoveRoleRequest

Request to move one role in the role order. Role order is the
administrative rank; see ADR-114.

| Field | Type | Description |
| --- | --- | --- |
| `role_name` | `string` | Required role to move. Owner and everyone cannot move. |
| `before_role_name` | `optional string` | Role that follows the moved role in display order, which is highest first. The moved role then ranks directly above it. Omit to place the role lowest, directly above everyone. |


<a id="chatto-admin-v1-MoveRoleResponse"></a>

#### Result: MoveRoleResponse

Result of moving one role.

| Field | Type | Description |
| --- | --- | --- |
| `roles` | repeated [`AdminRole`](/reference/connectrpc-api/types/#chatto-admin-v1-AdminRole) | Full role catalog after the move, in role order, highest first. |
