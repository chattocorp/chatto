## 回覆與討論串

在訊息上選擇**在討論串中回覆**，讓回覆留在同一段對話中。若要用新訊息開始討論串，請在傳送前選擇編輯器中的**發佈為討論串**。聊天室會保持開啟；選擇訊息的討論串連結即可開啟討論串。

開啟的討論串有自己的網址。複製瀏覽器網址，即可分享給有權存取聊天室的人。關閉討論串會返回聊天室，不會取消追蹤該對話。

<p>如果你希望回覆時仍能看到聊天室，請開啟
<a href={resolve('/chat/preferences/appearance')}>應用程式偏好設定 → 外觀</a>，
將<strong>討論串窗格</strong>設為<strong>並排</strong>。空間不足時，Chatto 會將討論串顯示在聊天室上方。</p>

## 追蹤對話

選擇**追蹤討論串**，將對話保留在**討論串**清單中。不必發送訊息也能追蹤討論串。

在**討論串**中，**已追蹤**顯示你追蹤的討論串。**我的**顯示你發起且仍在追蹤的討論串。取消追蹤會將其從兩個檢視中移除。選擇**未讀**可尋找有未讀回覆的對話。

搜尋欄會搜尋你追蹤的討論串中的訊息和回覆，包括私人訊息討論串。你可以搜尋單字、加上引號的詞句，或使用 `from:username` 搜尋作者。只有伺服器支援並啟用搜尋時才能使用此功能。

## 在聊天室和未讀活動之間切換

按 **Ctrl+K**（Mac 上為 **Command+K**）開啟快速切換器。在其中搜尋，即可切換聊天室和伺服器，不必逐項瀏覽側邊欄。

按 **Alt+Shift+Down**（Mac 上為 **Option+Shift+Down**），可跳至你已登入的所有伺服器中的下一個未讀來源。Chatto 會先顯示重要通知，再顯示其他通知，最後顯示有未讀圓點的聊天室。目前的訊息草稿會保留。

應用程式頂端的鈴鐺會開啟所有已登入伺服器的通知。閱讀聊天室或討論串時，只會將你能看到的訊息及之前的通知標為已讀。開啟舊訊息不會將較新的回覆標為已讀。

按 **Ctrl+Shift+K**（Mac 上為 **Command+Shift+K**）查看可用的鍵盤快速鍵。

## 選擇要通知你的活動

開啟伺服器的**通知**設定，調整提及、回覆、反應及其他活動的提醒。每項設定可套用至整個伺服器、聊天室群組或單一聊天室。

- **繼承**使用聊天室群組或伺服器的設定。
- **關閉**不會為這類活動產生通知或未讀圓點。
- **未讀圓點**標記聊天室，但不產生通知。
- **應用程式內通知**會在通知中心新增一筆記錄。
- **推播通知**也允許在已啟用通知的裝置上顯示提醒。

例如，如果你想自行安排時間查看一般聊天，可以為新的聊天室訊息選擇**未讀圓點**，為直接提及選擇**推播通知**。

<p>推播提醒也需要裝置許可。在手機上，請按照
<a href={resolve('/help/[topic]', { topic: 'phone' })}>在手機上安裝 Chatto</a>
的步驟安裝應用程式並啟用通知。手機的通知設定決定是否在鎖定畫面上顯示姓名和訊息預覽。</p>

## 連線中斷時

已載入的訊息仍然可見，但 Chatto 需要連線至伺服器才能載入更多訊息或傳送回覆。連線恢復後，它會載入錯過的更新。

如果傳送失敗，草稿會保留在編輯器中。它不會排入佇列等待自動傳送：請檢查連線並重新傳送。在手機上安裝 Chatto 並不會讓聊天記錄可供離線查看。
