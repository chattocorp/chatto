你可以用 Markdown 設定 Chatto 訊息的格式。例如，`**你好**` 會顯示為**你好**。你可以自行輸入格式標記，也可以選取文字後使用格式工具列。

## 選擇編輯器和傳送快速鍵

開啟 <a href={resolve('/chat/preferences/composer')}>應用程式偏好設定 → 訊息編輯</a>，選擇 **Markdown** 來編輯原始文字。如果你偏好直接編輯有格式的文字，請選擇**視覺化**。兩種編輯器都提供格式工具列。

**傳送訊息的按鍵**設定控制 Enter 鍵：

- **Enter：**Enter 傳送訊息。Ctrl+Enter 插入新行，Mac 上為 Command+Enter。
- **Cmd/Ctrl+Enter：**Ctrl+Enter 傳送訊息，Mac 上為 Command+Enter。Enter 插入新行。

段落之間留一個空白行。

## 粗體、斜體、底線和刪除線

在文字兩側放置格式標記：

- `**粗體**` 表示粗體
- `*斜體*` 表示斜體
- `__底線__` 表示底線
- `~~刪除線~~` 表示刪除線

<MarkdownSample source={"請在 **週五之前** 審查。\n日期是 *暫定的*。\n__需要核准__ 後才能發佈。\n原本的截止日期是 ~~週四~~。"} />

在 Chatto 中，`__文字__` 表示底線。如果你在其他 Markdown 工具中用雙底線表示粗體，請在這裡改用雙星號。

選取文字，按 Ctrl+B、Ctrl+I 或 Ctrl+U 可設定粗體、斜體或底線。Mac 上用 Command 取代 Ctrl。工具列按鈕執行相同操作。

標記與文字之間不要留空格：`**重要**` 有效；`** 重要 **` 不會變成粗體。

## 標題和清單

標題以 `#` 開頭，後接一個空格。每個項目符號以 `- ` 開頭，編號項目以數字和英文句點開頭，例如 `1. `。

<MarkdownSample source={"## 發佈檢查清單\n\n開始前：\n- 確認版本。\n- 通知支援團隊。\n\n然後：\n1. 部署更新。\n2. 檢查狀態頁面。\n3. 在這裡發佈結果。"} />

工具列中的**標題**按鈕會插入第二級標題（`##`）。你也可以自行輸入 `#` 到 `######` 來指定標題層級。

使用**增加縮排**將清單項目巢狀排列在前一項下，使用**減少縮排**將其移回。清單之後留一個空白行，再開始新段落。

## 引用

每行引用以 `>` 和一個空格開頭。在引用之後留一個空白行，再寫回覆。

<MarkdownSample source={"> 我們能把發佈改到週五嗎？\n\n可以。最後審查在週四下午。"} />

輸入引用不會將其連結至原始訊息。若要在討論串中回覆該訊息，請使用訊息的回覆操作。

## 程式碼

在短指令、檔案名稱或識別碼兩側各放一個反引號。行內程式碼中的格式標記會原樣顯示。

<MarkdownSample source={"開始前執行 `git status`。\n該設定稱為 `send_mode`。\n輸入 `**你好**` 可讓「你好」變成粗體。"} />

多行程式碼需要在程式碼前後各放一行三個反引號。在開頭的反引號後直接加上語言名稱，例如 `js`、`json` 或 `bash`，即可啟用語法醒目提示。

<MarkdownSample source={"```js\nconst release = '0.5';\nconsole.log(release);\n```"} />

工具列中的**程式碼區塊**按鈕會插入開頭和結尾的反引號。如果缺少結尾行，訊息的剩餘部分都會成為程式碼區塊。若要在行內程式碼中顯示反引號，請在文字兩側使用兩個反引號。

## 連結

貼上的網址會成為連結。若要顯示標籤而非網址，請將標籤放在方括號中，網址放在圓括號中：

```text
閱讀[版本說明](https://example.com/releases)。
```

`]` 與 `(` 之間不要留空格。若要連結至 Chatto 聊天室或提及某個人，請從編輯器的建議中選擇。

## 註腳

在需要註解的文字後加入 `[^window]` 這樣的參照。在獨立一行寫下 `[^window]:`，後接註解。兩處標籤必須一致。

<MarkdownSample source={"維護時段為 30 分鐘。[^window]\n\n[^window]: 大多數伺服器的無法使用時間將少於五分鐘。"} />

你也可以將游標放在相關文字後，選擇工具列中的**插入註腳**。行內程式碼或程式碼區塊中不能插入註腳。

## 表格

用 `|` 分隔欄，在欄標題下放一行連字號。用 `---:` 將欄靠右對齊，用 `:---:` 將欄置中。

<MarkdownSample source={"| 環境 | 版本 |\n| --- | ---: |\n| 測試 | 0.5 |\n| 正式環境 | 0.4 |"} />

請在 Markdown 編輯器中編輯表格。視覺化編輯器沒有表格編輯控制項。

## 格式顯示不正確時

- **標記仍然可見。**檢查兩端的標記是否相符，開頭標記後和結尾標記前是否沒有空格。程式碼中的標記本來就應該可見。
- **訊息的剩餘部分看起來都像程式碼。**將結尾的三個反引號放在獨立一行。
- **標題或清單仍是一般文字。**在 `##`、`-` 或 `1.` 後加一個空格，並從新行開始。
- **你想顯示標點本身。**在格式標記前放一個反斜線，例如 `\*不是斜體\*`，或使用行內程式碼展示原文。
- **HTML 顯示為文字。**Chatto 不接受原始 HTML 作為訊息格式。請使用 Markdown，而非 `<b>` 或 `<span>` 等標籤。
