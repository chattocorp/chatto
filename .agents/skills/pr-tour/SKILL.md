---
name: pr-tour
description: A skill that provides a guided tour of a pull request, highlighting key changes, walking the developer through the code, and explaining the purpose of each modification.
---

- Familiarize yourself with the changes contained in the Pull Request, including unchanged or even uncommited changes.
- Present the user with a guided tour of the changes, starting with a high-level summary of the modifications, followed by a list of noteworthy changes, grouped into categories (find categories that make sense in the context of the change!)
- Keep things concise and high-level. Don't go into too much detail about the code itself, but rather focus on the purpose and impact of the changes. Leave it to the user to explore the code if they want to dive deeper.
