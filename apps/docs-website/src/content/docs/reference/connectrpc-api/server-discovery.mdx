## ServerDiscoveryService

Provides unauthenticated server discovery metadata.

<a id="chatto-discovery-v1-ServerDiscoveryService-GetServer"></a>

### GetServer

Returns public server metadata, branding, registration status, and login
provider information. This fully public RPC is available before login so
clients can render the first server screen and authentication choices.

```http
POST /api/connect/chatto.discovery.v1.ServerDiscoveryService/GetServer
```

<a id="chatto-discovery-v1-GetServerRequest"></a>

#### Input: GetServerRequest

Request for public server metadata.


<a id="chatto-discovery-v1-GetServerResponse"></a>

#### Result: GetServerResponse

Public metadata clients need before they can authenticate or render the
initial server view.

| Field | Type | Description |
| --- | --- | --- |
| `profile` | [`chatto.api.v1.ServerPublicProfile`](/reference/connectrpc-api/types/#chatto-api-v1-ServerPublicProfile) | Public server profile and branding. |
| `login` | [`chatto.api.v1.ServerLogin`](/reference/connectrpc-api/types/#chatto-api-v1-ServerLogin) | Login and registration options. |
| `setup_required` | `bool` | Whether first-run setup is available before normal registration. |

<a id="chatto-discovery-v1-ServerDiscoveryService-ListNeighborhoodServers"></a>

### ListNeighborhoodServers

Returns the Neighborhood without requiring a session. The server
contacts other servers in the background and caches the result. A call
does not contact other servers, so a client can show the Neighborhood
without revealing the user's network address to those servers. The
server refreshes the Neighborhood at least once per hour and soon after
its Neighbors change.

```http
POST /api/connect/chatto.discovery.v1.ServerDiscoveryService/ListNeighborhoodServers
```

<a id="chatto-discovery-v1-ListNeighborhoodServersRequest"></a>

#### Input: ListNeighborhoodServersRequest

Request for the Neighborhood that this server has discovered.


<a id="chatto-discovery-v1-ListNeighborhoodServersResponse"></a>

#### Result: ListNeighborhoodServersResponse

Servers that the called server discovered through its Neighbors. The
called server lists each of its Neighbors whose public profile loaded. It
also lists servers that a mutually advertising Neighbor recommends when the
recommendation is also mutual. The response has no ordering contract.

| Field | Type | Description |
| --- | --- | --- |
| `servers` | repeated [`NeighborhoodServer`](/reference/connectrpc-api/types/#chatto-discovery-v1-NeighborhoodServer) | Servers in the Neighborhood. |
| `refreshed_at` | `google.protobuf.Timestamp` | Time when the called server last completed Neighborhood discovery. Absent before the first completed discovery. |
