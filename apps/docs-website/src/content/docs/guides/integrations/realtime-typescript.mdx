This tutorial builds a small browser-based event client. It processes semantic
events in order and reconnects with its last safe cursor. It also shows how a
projection client can apply an exact resource snapshot. The same pattern works
for a bot runtime that provides a WebSocket implementation.

<Aside type="caution">
  Chatto's public API is experimental before 1.0. Generate bindings from the
  exact Chatto release that your server runs. Do not mix schemas from different
  releases.
</Aside>

## Before you start

You need:

- a Chatto server URL, such as `https://chat.example.com`;
- a bearer credential for a user or bot that can read the required activity;
- [Buf](https://buf.build/docs/cli/installation/) and Node.js; and
- the `proto/` directory from the exact Chatto server release.

Keep the credential out of source control, logs, URLs, screenshots, and support
requests. The example receives it from its caller and does not print it.

## Generate TypeScript bindings

<Steps>

1. Create a client project and install the protobuf runtime.

   ```sh
   mkdir chatto-realtime-client
   cd chatto-realtime-client
   npm init -y
   npm install @bufbuild/protobuf@1.10.1
   npm install --save-dev @bufbuild/protoc-gen-es@1.10.1 typescript vite
   npm pkg set type=module scripts.dev=vite scripts.check="tsc --noEmit"
   ```

2. Copy the matching Chatto release's `proto/` directory into the project.
   Keep its `buf.yaml` file and all imported API definitions.

3. Create `tsconfig.json` in the project root.

   ```json
   {
     "compilerOptions": {
       "target": "ES2022",
       "module": "NodeNext",
       "moduleResolution": "NodeNext",
       "lib": ["ES2022", "DOM"],
       "strict": true,
       "noEmit": true
     },
     "include": ["src"]
   }
   ```

4. Create `buf.gen.yaml` in the project root.

   ```yaml
   version: v2
   plugins:
     - local: node_modules/.bin/protoc-gen-es
       out: src/gen
       opt:
         - target=ts
   ```

5. Generate the bindings.

   ```sh
   buf generate proto --template buf.gen.yaml
   ```

</Steps>

The client below imports from the generated
`src/gen/chatto/realtime/v1/realtime_pb.ts` file.

## Create an event client

Create `src/realtime.ts`:

```ts
import {
  RealtimeClientFrame,
  RealtimeClientHello,
  RealtimeErrorCode,
  RealtimeEvent,
  RealtimeInitialState,
  RealtimeRecoveryMode,
  RealtimeServerFrame,
  RealtimeSnapshot,
  RealtimeSubscribeEvents,
} from "./gen/chatto/realtime/v1/realtime_pb.js";

const PROTOCOL_VERSION = 4;
const BASE_RECONNECT_MS = 1_000;
const MAX_RECONNECT_MS = 30_000;

function durationMs(value?: { seconds: bigint; nanos: number }): number {
  return value ? Number(value.seconds) * 1_000 + value.nanos / 1_000_000 : 0;
}

type ChattoRealtimeClientOptions = {
  initialState?: RealtimeInitialState;
  beginSnapshot?: () => void | Promise<void>;
  applySnapshot?: (snapshot: RealtimeSnapshot) => void | Promise<void>;
  completeSnapshot?: (cursor: string, signal: AbortSignal) => Promise<void>;
};

export class ChattoRealtimeClient {
  #socket?: WebSocket;
  #stopped = false;
  #reconnectAttempt = 0;
  #reconnectDelay?: number;
  #resumeCursor?: string;
  #lastFrameAt = 0;
  #heartbeatStallMs = 75_000;
  #watchdog?: number;
  #processing = Promise.resolve();
  #seenEventIds = new Set<string>();
  #connectionAbort?: AbortController;
  #snapshotInProgress = false;

  constructor(
    private readonly serverUrl: string,
    private readonly bearerToken: string,
    private readonly onEvent: (event: RealtimeEvent) => void | Promise<void>,
    private readonly options: ChattoRealtimeClientOptions = {},
  ) {}

  start(): void {
    this.#stopped = false;
    this.#connect();
  }

  stop(): void {
    this.#stopped = true;
    window.clearInterval(this.#watchdog);
    this.#connectionAbort?.abort();
    this.#socket?.close(1000, "client stopped");
  }

  #connect(): void {
    if (this.#stopped) return;
    this.#connectionAbort?.abort();
    const connectionAbort = new AbortController();
    this.#connectionAbort = connectionAbort;
    const url = new URL("/api/realtime", this.serverUrl);
    url.protocol = url.protocol === "https:" ? "wss:" : "ws:";

    const socket = new WebSocket(url);
    socket.binaryType = "arraybuffer";
    this.#socket = socket;
    this.#reconnectDelay = undefined;

    socket.onopen = () => {
      if (this.#stopped || this.#socket !== socket) return;
      this.#lastFrameAt = Date.now();
      this.#send(
        new RealtimeClientFrame({
          frame: {
            case: "hello",
            value: new RealtimeClientHello({
              protocolVersion: PROTOCOL_VERSION,
              bearerToken: this.bearerToken,
            }),
          },
        }),
      );
    };

    socket.onmessage = (message) => {
      if (this.#stopped || this.#socket !== socket) return;
      // Keep event handling ordered even when one handler is asynchronous.
      this.#processing = this.#processing
        .then(async () => {
          const bytes = await this.#binaryBytes(message.data);
          const frame = RealtimeServerFrame.fromBinary(bytes);
          this.#lastFrameAt = Date.now();
          await this.#handleFrame(frame, connectionAbort.signal);
        })
        .catch((error) => {
          console.error("Realtime frame rejected", error);
          socket.close(1008, "unsupported realtime frame");
        });
    };

    socket.onclose = () => {
      if (this.#socket !== socket) return;
      connectionAbort.abort();
      this.#socket = undefined;
      window.clearInterval(this.#watchdog);
      if (this.#stopped) return;

      const delay =
        this.#reconnectDelay ??
        Math.min(
          BASE_RECONNECT_MS * 2 ** this.#reconnectAttempt,
          MAX_RECONNECT_MS,
        );
      this.#reconnectAttempt += 1;
      window.setTimeout(() => this.#connect(), delay);
    };
  }

  async #handleFrame(
    frame: RealtimeServerFrame,
    connectionSignal: AbortSignal,
  ): Promise<void> {
    switch (frame.frame.case) {
      case "hello": {
        const hello = frame.frame.value;
        if (hello.protocolVersion !== PROTOCOL_VERSION) {
          this.#stopped = true;
          throw new Error("The server does not support realtime protocol 4");
        }
        const heartbeatMs = durationMs(hello.heartbeatInterval);
        this.#heartbeatStallMs =
          heartbeatMs > 0 ? Math.max(heartbeatMs * 3, 15_000) : 75_000;
        this.#startWatchdog();
        this.#send(
          new RealtimeClientFrame({
            frame: {
              case: "subscribeEvents",
              value: new RealtimeSubscribeEvents({
                initialState:
                  this.options.initialState ?? RealtimeInitialState.LIVE_ONLY,
                resumeCursor: this.#resumeCursor,
              }),
            },
          }),
        );
        return;
      }

      case "subscribed": {
        const subscribed = frame.frame.value;
        console.info(
          "Realtime recovery mode",
          RealtimeRecoveryMode[subscribed.recoveryMode],
        );
        this.#snapshotInProgress =
          subscribed.recoveryMode === RealtimeRecoveryMode.SNAPSHOT;
        if (this.#snapshotInProgress) {
          // A partial snapshot can never be a safe resume base.
          this.#resumeCursor = undefined;
          await this.options.beginSnapshot?.();
          connectionSignal.throwIfAborted();
        }
        return;
      }

      case "snapshot": {
        if (!this.#snapshotInProgress || !this.options.applySnapshot) {
          throw new Error("Unexpected realtime snapshot");
        }
        await this.options.applySnapshot(frame.frame.value);
        connectionSignal.throwIfAborted();
        return;
      }

      case "event": {
        const event = frame.frame.value;
        const eventId = event.id;
        if (eventId && !this.#seenEventIds.has(eventId)) {
          await this.onEvent(event);
          this.#seenEventIds.add(eventId);
        }
        // Save the cursor only after the complete handler succeeds. An unknown
        // additive event variant can be ignored and still advance this cursor.
        if (event.resumeCursor !== undefined) {
          this.#resumeCursor = event.resumeCursor;
        }
        return;
      }

      case "caughtUp": {
        const cursor = frame.frame.value.cursor;
        if (this.#snapshotInProgress) {
          await this.options.completeSnapshot?.(cursor, connectionSignal);
          connectionSignal.throwIfAborted();
          this.#snapshotInProgress = false;
        }
        this.#resumeCursor = cursor;
        this.#reconnectAttempt = 0;
        return;
      }

      case "heartbeat": {
        const cursor = frame.frame.value.resumeCursor;
        if (cursor !== undefined) this.#resumeCursor = cursor;
        return;
      }

      case "pong":
        return;

      case "error": {
        const error = frame.frame.value;
        console.error("Realtime request failed", error.code, error.message);
        if (error.fatal) {
          const retryable = [
            RealtimeErrorCode.TEMPORARILY_UNAVAILABLE,
            RealtimeErrorCode.REPLAY_UNAVAILABLE,
            RealtimeErrorCode.SUBSCRIBE_FAILED,
          ].includes(error.code);
          this.#stopped = !retryable;
          this.#reconnectDelay =
            durationMs(error.retryAfter) || BASE_RECONNECT_MS;
          this.#socket?.close(1008, "fatal realtime error");
        }
        return;
      }

      case "close": {
        const close = frame.frame.value;
        this.#stopped = !close.reconnect;
        this.#reconnectDelay =
          durationMs(close.retryAfter) || BASE_RECONNECT_MS;
        this.#socket?.close(1000, "server requested reconnect");
        return;
      }

      case undefined:
        throw new Error("Unknown realtime server frame");
    }
  }

  #startWatchdog(): void {
    window.clearInterval(this.#watchdog);
    this.#watchdog = window.setInterval(() => {
      if (Date.now() - this.#lastFrameAt >= this.#heartbeatStallMs) {
        this.#socket?.close(1012, "heartbeat stalled");
      }
    }, 5_000);
  }

  #send(frame: RealtimeClientFrame): void {
    if (this.#socket?.readyState !== WebSocket.OPEN) {
      throw new Error("Realtime socket is not open");
    }
    this.#socket.send(Uint8Array.from(frame.toBinary()).buffer);
  }

  async #binaryBytes(data: unknown): Promise<Uint8Array> {
    if (data instanceof ArrayBuffer) return new Uint8Array(data);
    if (data instanceof Blob) return new Uint8Array(await data.arrayBuffer());
    throw new Error("Expected a binary protobuf frame");
  }
}
```

## Handle the events that your bot needs

Pass the access credential from a secure runtime source. Switch on the public
event variant and use ConnectRPC when you need the current resource.

```ts
import { ChattoRealtimeClient } from "./realtime.js";

const client = new ChattoRealtimeClient(
  "https://chat.example.com",
  accessToken,
  async (event) => {
    switch (event.event.case) {
      case "messagePosted":
        console.info("New message ID", event.id);
        break;
      case "reactionAdded":
        console.info("Reaction", event.event.value.emoji);
        break;
      default:
        // Ignore event variants that this integration does not use.
        break;
    }
  },
);

client.start();
```

Do not put the token in the WebSocket URL or a log message. Rotate an expiring
OAuth access credential before you reconnect.

The in-memory event-ID set only shows the deduplication rule. A bot that can
restart must store completed event IDs or an equivalent idempotency record with
its effects. The realtime cursor repairs a recent connection gap. It is not an
indefinite durable queue.

## Build a projection client

A projection client selects `RealtimeInitialState.SNAPSHOT`. When
`subscribed.recoveryMode` is `SNAPSHOT`, clear realtime-owned state. Apply each
snapshot frame as a complete replacement for that resource family. The server
closes the exact snapshot boundary with `caught_up` and then sends later events.

Pass snapshot lifecycle functions when you create the client:

```ts
import { RealtimeInitialState } from "./gen/chatto/realtime/v1/realtime_pb.js";

const projectionClient = new ChattoRealtimeClient(
  "https://chat.example.com",
  accessToken,
  applyOrReconcileEvent,
  {
    initialState: RealtimeInitialState.SNAPSHOT,
    beginSnapshot: () => resetProjection(),
    applySnapshot: (snapshot) => {
      switch (snapshot.resource.case) {
        case "server":
          replaceServerProfile(snapshot.resource.value);
          break;
        case "rooms":
          replaceRooms(snapshot.resource.value.rooms);
          break;
        case "roomGroups":
          replaceRoomGroups(snapshot.resource.value.roomGroups);
          break;
        case "users":
          replaceReferencedUsers(snapshot.resource.value.users);
          break;
        case "activeCalls":
          replaceActiveCalls(snapshot.resource.value.activeCalls);
          break;
        case undefined:
          throw new Error("Unknown snapshot resource");
      }
    },
    completeSnapshot: async (cursor, signal) => {
      const headers = { "Chatto-Realtime-Minimum-Cursor": cursor };
      const [runtime, viewer, notifications] = await Promise.all([
        serverClient.getRuntimeConfig(
          {},
          { headers, signal, timeoutMs: 10_000 },
        ),
        viewerClient.getViewer({}, { headers, signal, timeoutMs: 10_000 }),
        notificationClient.listNotificationOccurrences(
          {},
          { headers, signal, timeoutMs: 10_000 },
        ),
      ]);
      signal.throwIfAborted();
      replaceAuxiliaryState({ runtime, viewer, notifications });
    },
  },
);

projectionClient.start();
```

This example assumes generated ConnectRPC clients and replacement functions
for the local projection. The users snapshot contains the viewer and users
that snapshot resources reference. It is not the complete user directory.
Load other users with bounded `BatchGetUsers` calls when later events reference
them.

Notifications, runtime settings, and some viewer state are not part of the
exact content snapshot. The example reads them after `caught_up` with the same
cursor as a minimum boundary. Use a finite deadline for every cursor-bounded
call. Associate each snapshot with a local generation or abort signal. When a
newer snapshot starts, discard responses from the earlier generation.

A targeted ConnectRPC response can include changes after its minimum cursor.
Make direct reducers idempotent, or use the event to read and replace the
affected resource. Save an event cursor only after every required read
succeeds.

Do not infer old history from the realtime stream. Use ConnectRPC for commands,
explicit reads, room or thread history, paginated lists, files, pins, and
searches. Treat public events as refresh hints for resources that the
client has loaded.
