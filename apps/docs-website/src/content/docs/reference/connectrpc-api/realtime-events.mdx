## Event

This catalogue contains the canonical event variants that Chatto can send through `RealtimeEvent.event`. It is a public subset of `chatto.core.evt.v1.Event`. Internal variants and storage-only fields are excluded. The page is generated from the runtime public-event catalogue and the protobuf field-surface rules.

The canonical event package is public because protocol 4 puts this message directly on the wire. The package name still reflects the persisted compatibility contract. It does not mean that the server sends stored bytes.

Every canonical event also contains these common fields:

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Stable event identifier. |
| `created_at` | `google.protobuf.Timestamp` | Time when Chatto created the event. |
| `actor_id` | `string` | Visible user that caused the event, when applicable. |

The opaque resume cursor is part of the surrounding `RealtimeEvent`, not the canonical event.

### MessagePostedEvent

`chatto.core.evt.v1.MessagePostedEvent`

| Field | Type | Description |
| --- | --- | --- |
| `room_id` | `string` | Room ID - identifies which room this message belongs to |
| `in_reply_to` | `string` | Threading: event ID of the message this is replying to (empty = top-level message) |
| `in_thread` | `string` | Threading: event ID of the thread root message (empty = top-level message) For direct replies to a root, in_thread == in_reply_to. For nested replies, in_thread references the original root. |
| `mentioned_user_ids` | repeated `string` | User IDs selected by valid resolved mentions. This is a flattened view of direct, role, @here, and @all recipients and does not identify which cause selected a user. Use mentions whenever policy or cause depends on mention provenance; older events may have only mentioned_user_ids. |
| `echo_of_event_id` | `string` | Event ID of the original thread reply this echoes (empty = not an echo) |
| `echo_from_thread_root_event_id` | `string` | Thread root event ID — the thread this echo originates from (empty = not an echo) |
| `mentions` | repeated [`MessageMention`](#chatto-core-evt-v1-MessageMention) | Resolved mention facts at the time this message was accepted. Unlike mentioned_user_ids, these preserve whether each recipient was selected by a direct, role, presence-scoped, or room-wide mention. Derived consumers can therefore apply the correct policy without re-parsing message content or consulting newer room state. |
| `body_plaintext` | optional `string` | Decrypted message text for authorized realtime delivery. |
