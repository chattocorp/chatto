## ViewerService

Provides authenticated user profile, preferences, and capability state.

<a id="chatto-api-v1-ViewerService-GetViewer"></a>

### GetViewer

Returns the current authenticated viewer. This RPC requires a logged-in
user; unauthenticated callers receive an UNAUTHENTICATED error.

```http
POST /api/connect/chatto.api.v1.ViewerService/GetViewer
```

<a id="chatto-api-v1-GetViewerRequest"></a>

#### Input: GetViewerRequest

Request for the authenticated viewer snapshot.


<a id="chatto-api-v1-GetViewerResponse"></a>

#### Result: GetViewerResponse

Authenticated viewer snapshot needed by application shells.

| Field | Type | Description |
| --- | --- | --- |
| `user` | [`ViewerUser`](/reference/connectrpc-api/types/#chatto-api-v1-ViewerUser) | Current authenticated user. |
| `capabilities` | [`ViewerCapabilities`](/reference/connectrpc-api/types/#chatto-api-v1-ViewerCapabilities) | Permission-derived capabilities. |
| `viewer_permissions` | [`ServerViewerPermissions`](/reference/connectrpc-api/types/#chatto-api-v1-ServerViewerPermissions) | Effective server/channel permission decisions for the authenticated user. |
| `viewer_state` | [`ServerViewerState`](/reference/connectrpc-api/types/#chatto-api-v1-ServerViewerState) | Non-permission server state for the authenticated user. |
| `privileged_mode` | [`PrivilegedModeState`](/reference/connectrpc-api/types/#chatto-api-v1-PrivilegedModeState) | Explicit privilege activation state for this authenticated session. |


<a id="chatto-api-v1-ViewerService-ActivatePrivilegedMode"></a>

### ActivatePrivilegedMode

Activates elevation-required permissions for a fixed, non-sliding window.
Returns FAILED_PRECONDITION when the caller is a bot or has no eligible
permission entitlement.

```http
POST /api/connect/chatto.api.v1.ViewerService/ActivatePrivilegedMode
```

<a id="chatto-api-v1-ActivatePrivilegedModeRequest"></a>

#### Input: ActivatePrivilegedModeRequest

Request to activate all currently entitled elevation-required permissions.


<a id="chatto-api-v1-ActivatePrivilegedModeResponse"></a>

#### Result: ActivatePrivilegedModeResponse

Result of activating privileged mode for the current session.

| Field | Type | Description |
| --- | --- | --- |
| `privileged_mode` | [`PrivilegedModeState`](/reference/connectrpc-api/types/#chatto-api-v1-PrivilegedModeState) | Current privileged-mode state after activation. |


<a id="chatto-api-v1-ViewerService-DeactivatePrivilegedMode"></a>

### DeactivatePrivilegedMode

Deactivates elevation-required permissions immediately. Returns
FAILED_PRECONDITION when the caller is a bot.

```http
POST /api/connect/chatto.api.v1.ViewerService/DeactivatePrivilegedMode
```

<a id="chatto-api-v1-DeactivatePrivilegedModeRequest"></a>

#### Input: DeactivatePrivilegedModeRequest

Request to deactivate all elevation-required permissions for this session.
