Vous pouvez installer Chatto depuis le navigateur de votre téléphone. L'application dispose d'une icône sur l'écran d'accueil et s'ouvre dans sa propre fenêtre, sans barre d'adresse.

Utilisez l'adresse Chatto à laquelle vous vous connectez habituellement, par exemple `https://chat.example.com`. Si vous avez reçu un lien dans une autre application, copiez-le d'abord dans votre navigateur. Une adresse HTTPS est nécessaire pour installer l'application et utiliser les notifications push.

## iPhone : installer depuis Safari

1. Ouvrez votre adresse Chatto dans **Safari**.
2. Ouvrez **Partager**, le carré avec une flèche vers le haut. Selon la présentation de Safari, vous devrez peut-être d'abord ouvrir le menu de la page.
3. Sélectionnez **Sur l'écran d'accueil**. Si l'option manque, utilisez **Modifier les actions** pour l'ajouter.
4. Laissez **Ouvrir comme app web** activé si Safari propose cette option, puis sélectionnez **Ajouter**.
5. Ouvrez Chatto depuis la nouvelle icône de l'écran d'accueil. Connectez-vous si nécessaire.

Consultez les [instructions d'installation d'Apple](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios) si les options diffèrent sur votre téléphone.

## Android : installer depuis Chrome

1. Ouvrez votre adresse Chatto dans **Chrome**.
2. Ouvrez le **menu à trois points** à côté de la barre d'adresse.
3. Sélectionnez **Installer et créer un raccourci**, puis **Installer**. Certaines versions proposent plutôt **Installer l'application** ou **Ajouter à l'écran d'accueil**.
4. Confirmez l'installation, puis ouvrez Chatto depuis son icône. Connectez-vous si nécessaire.

Consultez les [instructions d'installation de Google](https://support.google.com/chrome/answer/9658361?hl=en&co=GENIE.Platform%3DAndroid) pour les étapes actuelles dans Chrome.

### Si vous utilisez Firefox

Ouvrez votre adresse Chatto dans Firefox, ouvrez le **menu à trois points**, puis sélectionnez **Installer**. Sélectionnez **Ajouter automatiquement**, ou faites glisser l'icône sur votre écran d'accueil. Ouvrez ensuite Chatto depuis cette icône.

Consultez les [instructions d'installation de Mozilla](https://support.mozilla.org/en-US/kb/use-web-apps-firefox-android) pour Firefox sur Android.

## Activer les notifications

Ouvrez l'application installée avant d'activer les notifications. Sur iPhone, ouvrez donc Chatto depuis son icône sur l'écran d'accueil, pas depuis un onglet Safari.

1. Ouvrez les paramètres **Notifications** de votre serveur.
2. Activez **Notifications push sur cet appareil** et autorisez les notifications lorsque votre téléphone vous le demande.
3. Sélectionnez **Envoyer une notification de test** pour vérifier la réception.

L'installation de l'application n'accorde pas l'autorisation de notification. Si aucune alerte de test n'arrive, vérifiez les paramètres de notification du téléphone et le mode Concentration ou Ne pas déranger. Si Chatto indique que les notifications push ne sont pas disponibles sur le serveur, demandez à son administrateur d'activer Web Push.

Votre téléphone peut afficher les noms et aperçus des messages sur l'écran verrouillé. Modifiez les paramètres de notification du téléphone si vous ne souhaitez pas y afficher d'aperçus.

## Appels sur iPhone

Le son des appels dans l'application web installée peut se couper lorsque vous changez d'application ou verrouillez l'écran. Gardez Chatto ouvert et l'écran déverrouillé pendant un appel. Un onglet Safari normal peut être plus fiable pour les appels que l'application installée.

Si le son s'arrête, revenez dans Chatto et sélectionnez **Activer le son de l’appel** si cette option apparaît. Si le son ne revient pas, quittez l'appel et rejoignez-le à nouveau, ou rouvrez Chatto dans Safari. Gardez iOS à jour ; le comportement peut varier selon les versions.

## Utiliser plusieurs serveurs

Vous pouvez connecter plusieurs serveurs dans une même application Chatto installée et passer de l'un à l'autre. Si vous préférez une icône distincte pour chaque communauté, installez Chatto depuis l'adresse de chaque serveur.

L'application installée a toujours besoin d'une connexion pour charger les messages et envoyer des réponses. Elle ne télécharge pas votre historique pour une utilisation hors connexion.
