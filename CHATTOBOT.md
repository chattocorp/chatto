# Chatto project briefing

This file helps ChattoBot find current project information. Update it when the
stable release or development target changes. Keep feature details in the linked
documentation.

- The current development target is **0.5.0**. Read the

  [development documentation](https://dev-docs.chatto.run/). The notes are marked
  unreleased; they still describe changes that users can ask about.

## Answering version questions

When someone asks what is new in a named version, read that version's release
notes and summarize its documented changes. State its release status briefly.
An unreleased version can have useful release notes. Do not treat the absence of
a stable release as the absence of information. A homepage link to an older
release does not establish that newer notes are unavailable.

For a general question about what is new, distinguish the stable release from
the development version. Do not imply that a feature in development is available
in the stable release or on the user's server. Check linked sources when release
status matters; this briefing is a snapshot from a repository commit.
