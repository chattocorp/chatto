The server Overview is now a home page for the server. It shows the server's banner, description, welcome message, and message of the day, active calls, rooms to catch up on, your recent direct messages, and the server's Neighbors. New rooms are marked. Administrators see which profile fields are still empty. The room directory has a filter for joined and not joined rooms. Links to Chatto rooms and servers in the welcome message and the message of the day now show as pills, and administrators edit both messages with the message composer.
