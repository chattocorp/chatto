Chatto можно установить из браузера телефона. На главном экране появится значок, а приложение будет открываться в отдельном окне без адресной строки браузера.

Используйте адрес Chatto, по которому обычно входите в аккаунт, например `https://chat.example.com`. Если вы получили ссылку в другом приложении, сначала скопируйте её в браузер. Для установки приложения и push-уведомлений нужен адрес HTTPS.

## iPhone: установка из Safari

1. Откройте свой адрес Chatto в **Safari**.
2. Откройте **Поделиться** — квадрат со стрелкой вверх. В зависимости от расположения элементов Safari сначала может потребоваться открыть меню страницы.
3. Выберите **На экран «Домой»**. Если пункта нет, добавьте его через **Править действия**.
4. Оставьте **Открывать как веб-приложение** включённым, если Safari показывает эту настройку, затем выберите **Добавить**.
5. Откройте Chatto с помощью нового значка на главном экране. При необходимости войдите в аккаунт.

Если пункты на вашем телефоне отличаются, см. [инструкции Apple по установке](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios).

## Android: установка из Chrome

1. Откройте свой адрес Chatto в **Chrome**.
2. Откройте **меню с тремя точками** рядом с адресной строкой.
3. Выберите **Установить и создать ярлык**, затем **Установить**. В некоторых версиях пункт называется **Установить приложение** или **Добавить на главный экран**.
4. Подтвердите установку и откройте Chatto с помощью значка приложения. При необходимости войдите в аккаунт.

Актуальные шаги для Chrome приведены в [инструкциях Google по установке](https://support.google.com/chrome/answer/9658361?hl=en&co=GENIE.Platform%3DAndroid).

### Если вы используете Firefox

Откройте адрес Chatto в Firefox, откройте **меню с тремя точками** и выберите **Установить**. Выберите **Добавить автоматически** или перетащите значок на главный экран. Затем откройте Chatto с помощью этого значка.

См. [инструкции Mozilla для Firefox на Android](https://support.mozilla.org/en-US/kb/use-web-apps-firefox-android).

## Включите уведомления

Перед включением уведомлений откройте установленное приложение. На iPhone это означает запуск Chatto со значка на главном экране, а не во вкладке Safari.

1. Откройте настройки **Уведомления** вашего сервера.
2. Включите **Push-уведомления на этом устройстве** и разрешите уведомления, когда телефон запросит разрешение.
3. Выберите **Отправить тестовое уведомление**, чтобы проверить доставку.

Установка приложения не даёт разрешения на уведомления. Если тестовое оповещение не пришло, проверьте настройки уведомлений телефона и режим фокусирования или «Не беспокоить». Если Chatto сообщает, что push недоступен на сервере, попросите администратора включить Web Push.

Телефон может показывать имена и предпросмотр сообщений на экране блокировки. Если вы этого не хотите, измените настройки уведомлений телефона.

## Звонки на iPhone

При звонке в установленном веб-приложении звук может пропасть, если переключить приложение или заблокировать экран. Во время звонка держите Chatto открытым, а экран — разблокированным. Обычная вкладка Safari может работать со звонками надёжнее установленного приложения.

Если звук пропал, вернитесь в Chatto и выберите **Включить звук звонка**, если этот элемент появился. Если звук не восстановился, выйдите из звонка и присоединитесь снова либо откройте Chatto в Safari. Обновляйте iOS: поведение может различаться между версиями.

## Используйте несколько серверов

В одном установленном приложении Chatto можно подключиться к нескольким серверам и переключаться между ними. Если нужен отдельный значок для каждого сообщества, установите Chatto с адреса каждого сервера.

Установленному приложению всё равно требуется соединение для загрузки сообщений и отправки ответов. Оно не загружает историю чата для работы без сети.
