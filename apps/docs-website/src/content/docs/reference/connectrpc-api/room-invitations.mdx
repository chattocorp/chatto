## RoomInvitationService

Invitations grant membership only after the recipient accepts them.

<a id="chatto-api-v1-RoomInvitationService-CreateRoomInvitation"></a>

### CreateRoomInvitation

Requires room membership and room.invite. A duplicate from the same sender returns the pending invitation.
A pending invitation from a different sender returns INVALID_ARGUMENT.

```http
POST /api/connect/chatto.api.v1.RoomInvitationService/CreateRoomInvitation
```
