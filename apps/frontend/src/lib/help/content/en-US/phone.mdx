You can install Chatto from your phone's browser. It gets a Home Screen icon and
opens in its own window, without a browser address bar.

Use the Chatto address you normally sign in to, such as
`https://chat.example.com`. If you received a link inside another app, copy it
into your browser first. You need an HTTPS address to install the app and use
push notifications.

## iPhone: install from Safari

1. Open your Chatto address in **Safari**.
2. Open **Share**, the square with an upward arrow. Depending on your Safari
   layout, you may need to open the page menu first.
3. Select **Add to Home Screen**. If it is missing, use **Edit Actions** to add it.
4. Leave **Open as Web App** enabled if Safari shows that option, then select
   **Add**.
5. Open Chatto from the new Home Screen icon. Sign in if asked.

See [Apple's installation instructions](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)
if the options differ on your phone.

## Android: install from Chrome

1. Open your Chatto address in **Chrome**.
2. Open the **three-dot menu** beside the address bar.
3. Select **Install and create shortcut**, then **Install**. Some versions show
   **Install app** or **Add to Home screen** instead.
4. Confirm the installation, then open Chatto from its app icon. Sign in if asked.

See [Google's installation instructions](https://support.google.com/chrome/answer/9658361?hl=en&co=GENIE.Platform%3DAndroid)
for the current Chrome steps.

### If you use Firefox

Open your Chatto address in Firefox, open the **three-dot menu**, and select
**Install**. Select **Add automatically**, or drag the icon to your Home Screen.
Then open Chatto from that icon.

See [Mozilla's installation instructions](https://support.mozilla.org/en-US/kb/use-web-apps-firefox-android)
for Firefox on Android.

## Enable notifications

Open the installed app before you enable notifications. On iPhone, this means
opening Chatto from its Home Screen icon, not from a Safari tab.

1. Open your server's **Notifications** settings.
2. Enable **Push notifications on this device** and allow notifications when
   your phone asks.
3. Select **Send test notification** to check delivery.

Installing the app does not grant notification permission. If no test alert
arrives, check your phone's notification settings and Focus or Do Not Disturb
mode. If Chatto reports that push is unavailable on the server, ask its
administrator to enable Web Push.

Your phone can show names and message previews on the lock screen. Change this
in the phone's notification settings if you do not want previews shown there.

## Calls on iPhone

Calls in the installed web app can lose audio when you switch apps or lock the
screen. Keep Chatto open and the screen unlocked during a call. A normal Safari
tab can work more reliably for calls than the installed app.

If audio stops, return to Chatto and select **Enable call audio** if it appears.
If that does not restore audio, leave the call and join again, or reopen Chatto
in Safari. Keep iOS up to date; behavior can differ between versions.

## Use more than one server

You can connect to several servers in one installed Chatto app and switch
between them. If you prefer a separate icon for each community, install Chatto
from each server's address instead.

The installed app still needs a connection to load messages and send replies.
It does not download your chat history for offline use.
