Attachments, link previews, and code blocks no longer have an action bar. Their actions now show in a small button group in the top corner when you point at them or reach them with the keyboard. This applies to images, GIFs, videos, audio, files, link previews, social posts, YouTube and Vimeo videos, and the copy and Source/Render buttons of code blocks. On touch screens, the actions are always visible. Removing a link preview now uses a close icon.
