Sign-in pages show the server's welcome message instead of its description. Compact sign-in windows, which previously showed only the description, now show the welcome message in a scrollable area. The description appears in the Server Directory and on the Server information page. In General server settings, name and description are grouped as Profile, and the welcome message and message of the day as Messages. Each field explains where it appears and warns when its text comes close to the length limit, and the welcome message field is larger.
