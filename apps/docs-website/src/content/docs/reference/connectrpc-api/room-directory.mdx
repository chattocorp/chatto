## RoomDirectoryService

Reads room directory data.

<a id="chatto-api-v1-RoomDirectoryService-ListRooms"></a>

### ListRooms

Lists rooms visible to the current user. Defaults to active rooms; use
archive_filter to discover archived rooms or include both states. Channel
rooms require membership, room.list, or room/group room.manage for metadata.
DM membership exposes room and
participant metadata. Message-derived DM state also requires current
read permission. Accessible empty DMs are included. Returns up to 100 rooms
ordered by ID ascending; the default page size is 50.

```http
POST /api/connect/chatto.api.v1.RoomDirectoryService/ListRooms
```

<a id="chatto-api-v1-ListRoomsRequest"></a>

#### Input: ListRoomsRequest

Request for rooms visible to the current user.

| Field | Type | Description |
| --- | --- | --- |
| `scope` | [`RoomDirectoryScope`](/reference/connectrpc-api/types/#chatto-api-v1-RoomDirectoryScope) | Which room kinds to include. Defaults to all. |
| `archive_filter` | [`RoomArchiveFilter`](/reference/connectrpc-api/types/#chatto-api-v1-RoomArchiveFilter) | Archive state to include. Defaults to ACTIVE. Combined with scope; this filter does not grant access to hidden rooms. |
| `page` | [`PageRequest`](/reference/connectrpc-api/types/#chatto-api-v1-PageRequest) | Defaults to 50 rooms, capped at 100. Rooms are ordered by ID ascending. |


<a id="chatto-api-v1-ListRoomsResponse"></a>

#### Result: ListRoomsResponse

One live page of rooms visible to the current user. Changes between requests
can shift offsets. Follow page.has_more to read the complete directory.

| Field | Type | Description |
| --- | --- | --- |
| `rooms` | repeated [`RoomWithViewerState`](/reference/connectrpc-api/types/#chatto-api-v1-RoomWithViewerState) | Visible rooms matching both the room-kind scope and archive filter. |
| `page` | [`PageInfo`](/reference/connectrpc-api/types/#chatto-api-v1-PageInfo) | Count after visibility, scope, and archive filters, before pagination. |


<a id="chatto-api-v1-RoomDirectoryService-ListRoomGroups"></a>

### ListRoomGroups

Lists ordered channel groups and authorized entries as a finite snapshot.
Membership, room.list, or room.manage permits room metadata reads. Group
managers can read every room entry in that group, including hidden rooms.
archive_filter defaults to ACTIVE. ALL returns the complete layout of each
managed group. Metadata access does not grant membership or message access.

```http
POST /api/connect/chatto.api.v1.RoomDirectoryService/ListRoomGroups
```

<a id="chatto-api-v1-ListRoomGroupsRequest"></a>

#### Input: ListRoomGroupsRequest

Request ordered room groups with entries the caller can see or manage.

| Field | Type | Description |
| --- | --- | --- |
| `archive_filter` | [`RoomArchiveFilter`](/reference/connectrpc-api/types/#chatto-api-v1-RoomArchiveFilter) | Defaults to ACTIVE. This filter does not grant access to room metadata. |


<a id="chatto-api-v1-ListRoomGroupsResponse"></a>

#### Result: ListRoomGroupsResponse

Finite snapshot of ordered room groups visible to the current user.

| Field | Type | Description |
| --- | --- | --- |
| `groups` | repeated [`RoomGroup`](/reference/connectrpc-api/types/#chatto-api-v1-RoomGroup) | Channel room groups in sidebar order. |


<a id="chatto-api-v1-RoomDirectoryService-GetRoomGroup"></a>

### GetRoomGroup

Returns one ordered group by ID with the same entry permissions and
archive filter as ListRoomGroups. role.manage alone does not reveal hidden
rooms. Empty entries can mean no rooms match the filter or permissions.
Returns NOT_FOUND when the room group does not exist.

```http
POST /api/connect/chatto.api.v1.RoomDirectoryService/GetRoomGroup
```

### GetRoom

Returns one room's authorized metadata by ID. Channel visibility matches
ListRooms, including management access. DM rooms require membership. Returns
NOT_FOUND when the room does not exist and PERMISSION_DENIED when the room
exists and the caller has neither visibility nor management authority.

```http
POST /api/connect/chatto.api.v1.RoomDirectoryService/GetRoom
```
