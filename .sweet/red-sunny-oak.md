Sign-in pages now show the server's welcome message instead of its description. This includes compact sign-in windows, such as signing in to a server from the app, which previously showed only the description. The description is still shown in the Server Directory, on the Server information page, and in link previews. If your description is written as a greeting for people who sign in, move that text to the welcome message in the General server settings.

The General server settings group the name and description as Profile, and the welcome message and message of the day as Messages. Each field says where it appears. The welcome message and message of the day fields now stop at the server's length limits.
