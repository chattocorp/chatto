## MyAccountService

Self-service account, profile, display preference, presence,
custom-status, external identity, and account lifecycle commands for the
authenticated user.

<a id="chatto-api-v1-MyAccountService-UpdateProfile"></a>

### UpdateProfile

Updates the authenticated user's login, display name, and/or bio.

```http
POST /api/connect/chatto.api.v1.MyAccountService/UpdateProfile
```

<a id="chatto-api-v1-UpdateProfileRequest"></a>

#### Input: UpdateProfileRequest

Request to update the authenticated user's profile. Human and bot accounts
use this same self-service operation. update_mask selects fields to apply
or reset. Fields outside the mask stay unchanged.

| Field | Type | Description |
| --- | --- | --- |
| `display_name` | `optional string` | New non-empty display name. The server also rejects control and confusing invisible characters. |
| `login` | `optional string` | New login identifier, when changing it. The server accepts ASCII letters, digits, period, underscore, and hyphen, starting with a letter or digit. |
| `bio` | `optional string` | New Markdown biography, when changing it. Empty clears the bio. |
| `update_mask` | `google.protobuf.FieldMask` | Editable fields to apply or reset: display_name, login, bio. Omit to infer populated fields; * selects all editable fields. An explicit empty mask is invalid. Unselected values are ignored. Selected absent values reset the field to its default, subject to field validation. |


<a id="chatto-api-v1-UpdateProfileResponse"></a>

#### Result: UpdateProfileResponse

Result of a profile update.

| Field | Type | Description |
| --- | --- | --- |
| `user` | [`User`](/reference/connectrpc-api/types/#chatto-api-v1-User) | Updated user profile. |

### SetPresence

Updates the current user's live presence status. This state is transient:
clients should refresh it periodically while visible, and should stop
calling this RPC when the user chooses to appear offline.

```http
POST /api/connect/chatto.api.v1.MyAccountService/SetPresence
```

<a id="chatto-api-v1-SetPresenceRequest"></a>

#### Input: SetPresenceRequest

Request to update the current user's live presence status.

| Field | Type | Description |
| --- | --- | --- |
| `status` | [`PresenceStatus`](/reference/connectrpc-api/types/#chatto-api-v1-PresenceStatus) | Live status to store for the authenticated user. Offline is rejected. |
| `user_selected` | `bool` | True when this update comes from a deliberate user selection rather than automatic idle/refresh updates. Automatic updates do not overwrite an active manually selected Away or Do Not Disturb status from another client. |


<a id="chatto-api-v1-SetPresenceResponse"></a>

#### Result: SetPresenceResponse

Result of updating live presence.

| Field | Type | Description |
| --- | --- | --- |

### SetCustomStatus

Sets the current user's complete custom status. Emoji and text are required.
Omit expires_at for no expiry, or supply a future time.

```http
POST /api/connect/chatto.api.v1.MyAccountService/SetCustomStatus
```

<a id="chatto-api-v1-SetCustomStatusRequest"></a>

#### Input: SetCustomStatusRequest

Request to replace the current user's complete custom status. Emoji and text
are required. Omitted expires_at removes any previous expiry. Use
DeleteCustomStatus to clear the status.

| Field | Type | Description |
| --- | --- | --- |
| `emoji` | `string` | Short emoji marker displayed with the status. |
| `text` | `string` | User-written status text. |
| `expires_at` | `google.protobuf.Timestamp` | Optional future time after which clients should stop showing the status. |
