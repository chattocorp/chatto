Chatto はスマートフォンのブラウザーからインストールできます。ホーム画面にアイコンが追加され、ブラウザーのアドレスバーがない独立したウィンドウで開きます。

`https://chat.example.com` など、普段サインインしている Chatto のアドレスを使ってください。別のアプリ内でリンクを受け取った場合は、まずブラウザーにコピーします。アプリのインストールとプッシュ通知には HTTPS のアドレスが必要です。

## iPhone：Safari からインストールする

1. **Safari** で Chatto のアドレスを開きます。
2. 上向き矢印の付いた四角形の**共有**を開きます。Safari の表示によっては、先にページメニューを開く必要があります。
3. **ホーム画面に追加**を選びます。表示されない場合は、**アクションを編集**から追加します。
4. Safari に**Web アプリとして開く**が表示される場合は、有効のままにして**追加**を選びます。
5. ホーム画面の新しいアイコンから Chatto を開きます。求められた場合はサインインします。

端末の選択肢が異なる場合は、[Apple のインストール手順](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)を参照してください。

## Android：Chrome からインストールする

1. **Chrome** で Chatto のアドレスを開きます。
2. アドレスバーの横にある**3 点メニュー**を開きます。
3. **インストールとショートカットの作成**、**インストール**の順に選びます。バージョンによっては、**アプリをインストール**または**ホーム画面に追加**と表示されます。
4. インストールを確認し、アプリのアイコンから Chatto を開きます。求められた場合はサインインします。

Chrome の現在の手順は、[Google のインストール手順](https://support.google.com/chrome/answer/9658361?hl=en&co=GENIE.Platform%3DAndroid)を参照してください。

### Firefox を使う場合

Firefox で Chatto のアドレスを開き、**3 点メニュー**から**インストール**を選びます。**自動的に追加**を選ぶか、アイコンをホーム画面にドラッグします。そのアイコンから Chatto を開いてください。

[Mozilla の Android 版 Firefox の手順](https://support.mozilla.org/en-US/kb/use-web-apps-firefox-android)も参照してください。

## 通知を有効にする

通知を有効にする前に、インストールしたアプリを開きます。iPhone では、Safari のタブではなく、ホーム画面のアイコンから Chatto を開いてください。

1. サーバーの**通知**設定を開きます。
2. **このデバイスのプッシュ通知**を有効にし、端末から求められたら通知を許可します。
3. **テスト通知を送信します**を選び、届くか確認します。

アプリをインストールしただけでは通知は許可されません。テスト通知が届かない場合は、端末の通知設定と集中モードやサイレントモードを確認してください。サーバーでプッシュ通知を利用できないと Chatto が表示する場合は、管理者に Web Push の有効化を依頼してください。

端末はロック画面に名前やメッセージのプレビューを表示することがあります。表示したくない場合は、端末の通知設定を変更してください。

## iPhone での通話

インストールした Web アプリでの通話は、アプリを切り替えたり画面をロックしたりすると音声が途切れることがあります。通話中は Chatto を開いたまま、画面のロックを解除しておいてください。通常の Safari タブの方が、インストールしたアプリより通話が安定する場合があります。

音声が止まった場合は Chatto に戻り、**通話音声を有効にする**が表示されていれば選びます。復旧しない場合は、一度通話を退出して参加し直すか、Safari で Chatto を開き直してください。iOS を最新に保ってください。バージョンによって動作が異なる場合があります。

## 複数のサーバーを使う

1 つのインストール済み Chatto アプリから複数のサーバーに接続し、切り替えられます。コミュニティごとに別のアイコンが欲しい場合は、各サーバーのアドレスから Chatto をインストールしてください。

インストールしたアプリも、メッセージの読み込みや返信の送信には接続が必要です。チャット履歴をオフライン用にダウンロードするわけではありません。
