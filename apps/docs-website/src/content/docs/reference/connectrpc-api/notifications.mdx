## NotificationService

Reads, marks read, and deletes notifications for the authenticated viewer.

<a id="chatto-api-v1-NotificationService-GetNotificationOccurrence"></a>

### GetNotificationOccurrence

Gets one exact visible occurrence. Returns NOT_FOUND when it is absent,
deleted, expired, or no longer visible to the authenticated viewer.

```http
POST /api/connect/chatto.api.v1.NotificationService/GetNotificationOccurrence
```

<a id="chatto-api-v1-GetNotificationOccurrenceRequest"></a>

#### Input: GetNotificationOccurrenceRequest

Request one exact notification occurrence by stable ID.

| Field | Type | Description |
| --- | --- | --- |
| `notification_id` | `string` | Required stable occurrence ID. |


<a id="chatto-api-v1-GetNotificationOccurrenceResponse"></a>

#### Result: GetNotificationOccurrenceResponse

One exact notification occurrence.

| Field | Type | Description |
| --- | --- | --- |
| `notification` | [`NotificationOccurrence`](/reference/connectrpc-api/types/#chatto-api-v1-NotificationOccurrence) | Visible occurrence. Absence is reported as NOT_FOUND. |


<a id="chatto-api-v1-NotificationService-BatchGetNotificationOccurrences"></a>

### BatchGetNotificationOccurrences

Gets an explicit bounded set of visible occurrences. Missing or
inaccessible IDs are omitted and duplicate IDs are de-duplicated.

```http
POST /api/connect/chatto.api.v1.NotificationService/BatchGetNotificationOccurrences
```

<a id="chatto-api-v1-BatchGetNotificationOccurrencesRequest"></a>

#### Input: BatchGetNotificationOccurrencesRequest

Request an explicit bounded set of notification occurrences.

| Field | Type | Description |
| --- | --- | --- |
| `notification_ids` | `repeated string` | Stable occurrence IDs. Unknown, deleted, and currently invisible IDs are omitted. Repeated IDs are de-duplicated in first-seen request order. |


<a id="chatto-api-v1-BatchGetNotificationOccurrencesResponse"></a>

#### Result: BatchGetNotificationOccurrencesResponse

<a id="chatto-api-v1-NotificationService-ListNotificationOccurrences"></a>

### ListNotificationOccurrences

Lists exact Notifications 2.0 occurrences. Clients may derive temporary
presentation groups without changing occurrence identity or counts.

```http
POST /api/connect/chatto.api.v1.NotificationService/ListNotificationOccurrences
```

<a id="chatto-api-v1-ListNotificationOccurrencesRequest"></a>

#### Input: ListNotificationOccurrencesRequest

Request for one page of notification occurrences.

| Field | Type | Description |
| --- | --- | --- |
| `page` | [`PageRequest`](/reference/connectrpc-api/types/#chatto-api-v1-PageRequest) | Page request. Defaults to 50 results when absent or limit is zero. |


<a id="chatto-api-v1-ListNotificationOccurrencesResponse"></a>

#### Result: ListNotificationOccurrencesResponse

One page of exact notification occurrences.

| Field | Type | Description |
| --- | --- | --- |
| `occurrences` | repeated [`NotificationOccurrence`](/reference/connectrpc-api/types/#chatto-api-v1-NotificationOccurrence) | Occurrences newest activity first. |
| `page` | [`PageInfo`](/reference/connectrpc-api/types/#chatto-api-v1-PageInfo) | Page metadata. |
| `unread_count` | `int32` | Total unread occurrence count, independent of presentation grouping. |
| `next_expiry_at` | `google.protobuf.Timestamp` | Earliest expiry in the complete list, including occurrences outside this page. Clients refresh authoritative notification state at this boundary. |
| `room_unread_counts` | repeated [`NotificationRoomUnreadCount`](/reference/connectrpc-api/types/#chatto-api-v1-NotificationRoomUnreadCount) | Complete unread-occurrence counts by target room. This is independent of the bounded page so room indicators remain authoritative. |
| `important_unread_count` | `optional int32` | Exact unread occurrences with Important attention. Absent servers predate attention tiers, so clients should conservatively treat all unread occurrences as Important. |

<a id="chatto-api-v1-NotificationService-DeleteAllNotificationOccurrences"></a>

### DeleteAllNotificationOccurrences

Permanently deletes every visible occurrence current at the server's
authoritative mutation boundary. Callers must not retry this mutation
automatically because later activity may arrive after that boundary.

```http
POST /api/connect/chatto.api.v1.NotificationService/DeleteAllNotificationOccurrences
```
