Endpoint paths use the Connect convention:

`/api/connect/<fully-qualified-service>/<method>`

Use this reference when building clients against Chatto's public ConnectRPC API.

## ViewerService

Provides authenticated user profile, preferences, and capability state.

## MyAccountService

Self-service account, profile, avatar, display preference, presence,
custom-status, external identity, and account lifecycle commands for the
authenticated user.

<a id="chatto-api-v1-MyAccountService-UpdateProfile"></a>

### UpdateProfile

Updates the authenticated user's login, display name, and/or bio.

```http
POST /api/connect/chatto.api.v1.MyAccountService/UpdateProfile
```

<a id="chatto-api-v1-UpdateProfileRequest"></a>

#### Input: UpdateProfileRequest

Request to update the authenticated user's profile. Human and bot accounts
use this same self-service operation. At least one field must be present.

| Field | Type | Description |
| --- | --- | --- |
| `display_name` | `optional string` | New display name, when changing it. Empty clears the explicit display name. The server also rejects control and confusing invisible characters. |
| `login` | `optional string` | New login identifier, when changing it. The server accepts ASCII letters, digits, period, underscore, and hyphen, starting with a letter or digit. |
| `bio` | `optional string` | New Markdown biography, when changing it. Empty clears the bio. |

#### Result: UpdateProfileResponse

## AssetService

Reads room-scoped asset metadata and freshly signed asset URLs.

<a id="chatto-api-v1-AssetService-GetAsset"></a>

### GetAsset

Reads one asset. Authentication and room membership are required.
Channel-room assets also require message.read or a matching thread
relationship with message.read-interactions. DM membership authorizes DM
assets. Returns NOT_FOUND when the asset is missing, deleted, or owned by a
different room.

```http
POST /api/connect/chatto.api.v1.AssetService/GetAsset
```

#### Input: GetAssetRequest

Request to read one room-scoped asset with freshly signed URLs.

<a id="chatto-api-v1-GetAssetResponse"></a>
