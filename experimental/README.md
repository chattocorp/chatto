# Experiments

This directory contains prototypes. Their APIs and behavior can change without
compatibility guarantees. Each experiment owns its setup instructions and checks. Keep dependency
notices for new experiments in a local `NOTICE` file.

- [Gobotto](gobotto/README.md): a Go bot for Chatto with an OpenRouter agent loop.
- [Chatto Go SDK](chatto-go/README.md): the standalone experimental Go client.
- [Chatto Rust SDK](chatto-rs/README.md): the standalone experimental Rust client.
- [Chatto Native](chatto-native/README.md): the native GPUI client experiment.
- [Chatto GPUix](chatto-gpuix/README.md): the native Svelte and GPUix client experiment.
