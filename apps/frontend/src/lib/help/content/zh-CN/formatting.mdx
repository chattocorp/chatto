你可以用 Markdown 设置 Chatto 消息的格式。例如，`**你好**` 会显示为**你好**。你可以自行输入格式标记，也可以选中文本后使用格式工具栏。

## 选择编辑器和发送快捷键

打开 <a href={resolve('/chat/preferences/composer')}>应用偏好设置 → 消息编辑</a>，选择 **Markdown** 来编辑源文本。如果你更喜欢直接编辑带格式的文本，请选择**可视化**。两种编辑器都提供格式工具栏。

**发送消息的按键**设置控制 Enter 键：

- **Enter：**Enter 发送消息。Ctrl+Enter 插入新行，Mac 上为 Command+Enter。
- **Cmd/Ctrl+Enter：**Ctrl+Enter 发送消息，Mac 上为 Command+Enter。Enter 插入新行。

段落之间留一个空行。

## 粗体、斜体、下划线和删除线

在文本两侧放置格式标记：

- `**粗体**` 表示粗体
- `*斜体*` 表示斜体
- `__下划线__` 表示下划线
- `~~删除线~~` 表示删除线

<MarkdownSample source={"请在 **周五之前** 审核。\n日期是 *暂定的*。\n__需要批准__ 后才能发布。\n原来的截止日期是 ~~周四~~。"} />

在 Chatto 中，`__文本__` 表示下划线。如果你在其他 Markdown 工具中用双下划线表示粗体，请在这里改用双星号。

选中文本，按 Ctrl+B、Ctrl+I 或 Ctrl+U 可设置粗体、斜体或下划线。Mac 上用 Command 替代 Ctrl。工具栏按钮执行相同操作。

标记与文本之间不要留空格：`**重要**` 有效；`** 重要 **` 不会变成粗体。

## 标题和列表

标题以 `#` 开头，后跟一个空格。每个项目符号以 `- ` 开头，编号项以数字和英文句点开头，例如 `1. `。

<MarkdownSample source={"## 发布检查清单\n\n开始前：\n- 确认版本。\n- 通知支持团队。\n\n然后：\n1. 部署更新。\n2. 检查状态页面。\n3. 在这里发布结果。"} />

工具栏中的**标题**按钮会插入二级标题（`##`）。你也可以自行输入 `#` 到 `######` 来指定标题级别。

使用**增加缩进**将列表项嵌套在前一项下，使用**减少缩进**将其移回。列表之后留一个空行，再开始新段落。

## 引用

每行引用以 `>` 和一个空格开头。在引用之后留一个空行，再写回复。

<MarkdownSample source={"> 我们能把发布改到周五吗？\n\n可以。最终审核在周四下午。"} />

输入引用不会将其链接到原始消息。要在讨论串中回复该消息，请使用消息的回复操作。

## 代码

在短命令、文件名或标识符两侧各放一个反引号。行内代码中的格式标记会按原样显示。

<MarkdownSample source={"开始前运行 `git status`。\n该设置叫做 `send_mode`。\n输入 `**你好**` 可让“你好”变成粗体。"} />

多行代码需要在代码前后各放一行三个反引号。在开头的反引号后直接加上语言名称，例如 `js`、`json` 或 `bash`，即可启用语法高亮。

<MarkdownSample source={"```js\nconst release = '0.5';\nconsole.log(release);\n```"} />

工具栏中的**代码块**按钮会插入开头和结尾的反引号。如果缺少结尾行，消息的剩余部分都会成为代码块。要在行内代码中显示反引号，请在文本两侧使用两个反引号。

## 链接

粘贴的网址会成为链接。要显示标签而不是网址，请将标签放在方括号中，网址放在圆括号中：

```text
阅读[发布说明](https://example.com/releases)。
```

`]` 与 `(` 之间不要留空格。要链接到 Chatto 房间或提及某个人，请从编辑器的建议中选择。

## 脚注

在需要注释的文本后添加 `[^window]` 这样的引用。在单独一行写下 `[^window]:`，后跟注释。两处标签必须一致。

<MarkdownSample source={"维护窗口为 30 分钟。[^window]\n\n[^window]: 大多数服务器的不可用时间将少于五分钟。"} />

你也可以将光标放在相关文本后，选择工具栏中的**插入脚注**。行内代码或代码块中不能插入脚注。

## 表格

用 `|` 分隔列，在列标题下放一行短横线。用 `---:` 将列右对齐，用 `:---:` 将列居中。

<MarkdownSample source={"| 环境 | 版本 |\n| --- | ---: |\n| 测试 | 0.5 |\n| 生产 | 0.4 |"} />

请在 Markdown 编辑器中编辑表格。可视化编辑器没有表格编辑控件。

## 格式显示不正确时

- **标记仍然可见。**检查两端的标记是否匹配，开头标记后和结尾标记前是否没有空格。代码中的标记本来就应当可见。
- **消息的剩余部分看起来都像代码。**将结尾的三个反引号放在单独一行。
- **标题或列表仍是普通文本。**在 `##`、`-` 或 `1.` 后加一个空格，并从新行开始。
- **你想显示标点本身。**在格式标记前放一个反斜杠，例如 `\*不是斜体\*`，或使用行内代码展示原文。
- **HTML 显示为文本。**Chatto 不接受原始 HTML 作为消息格式。请使用 Markdown，而不是 `<b>` 或 `<span>` 等标签。
