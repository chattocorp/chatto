## BotService

Creates and manages bot accounts owned by human users. Bot API keys cannot
call this service.

<a id="chatto-api-v1-BotService-ListBots"></a>

### ListBots

Lists bots visible to the authenticated caller.

```http
POST /api/connect/chatto.api.v1.BotService/ListBots
```

<a id="chatto-api-v1-ListBotsRequest"></a>

#### Input: ListBotsRequest

Request bots visible to the caller. Owners see their own bots; callers with
bot.manage see every bot.

| Field | Type | Description |
| --- | --- | --- |
| `search` | `string` | Optional case-insensitive login or display-name search. |
| `page` | [`PageRequest`](/reference/connectrpc-api/types/#chatto-api-v1-PageRequest) | Page request. Defaults to 20 results when absent or limit is zero. |


<a id="chatto-api-v1-ListBotsResponse"></a>

#### Result: ListBotsResponse

Page of visible bots.

| Field | Type | Description |
| --- | --- | --- |
| `bots` | repeated [`Bot`](/reference/connectrpc-api/types/#chatto-api-v1-Bot) | Visible bots. |
| `page` | [`PageInfo`](/reference/connectrpc-api/types/#chatto-api-v1-PageInfo) | Page metadata. |


<a id="chatto-api-v1-BotService-GetBot"></a>

### GetBot

Gets one visible bot. Returns NOT_FOUND for an unknown bot and
PERMISSION_DENIED for a bot managed by another user.

```http
POST /api/connect/chatto.api.v1.BotService/GetBot
```

<a id="chatto-api-v1-GetBotRequest"></a>

#### Input: GetBotRequest

Request one bot by stable user ID.

| Field | Type | Description |
| --- | --- | --- |
| `bot_user_id` | `string` | Required bot user ID. |


<a id="chatto-api-v1-GetBotResponse"></a>

#### Result: GetBotResponse

Response containing one bot.

| Field | Type | Description |
| --- | --- | --- |
| `bot` | [`Bot`](/reference/connectrpc-api/types/#chatto-api-v1-Bot) | Requested bot. |

### CreateBot

```http
POST /api/connect/chatto.api.v1.BotService/CreateBot
```

<a id="chatto-api-v1-CreateBotRequest"></a>

#### Input: CreateBotRequest

| Field | Type | Description |
| --- | --- | --- |
| `login` | `string` | Bot login. Must end in `_bot`. |
| `display_name` | `string` | Public display name. |


<a id="chatto-api-v1-CreateBotResponse"></a>

#### Result: CreateBotResponse
