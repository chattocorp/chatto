The server Overview is now a home page for the server. It shows the server's banner, description, welcome message, and message of the day, active calls, rooms and direct messages with unread activity, and the server's Neighbors. Rooms show as tiles that you can filter by joined and not joined, and new rooms are marked. Links to Chatto rooms and servers in the welcome message and the message of the day show as pills, and the chat header shows only the first line of a multi-line message of the day. Administrators edit both messages with the message composer and see which public profile fields are still empty.
